# heimdall

Asistente personal y módulo NBA. El modelo de lenguaje interpreta y explica; Python calcula; SQLite conserva los datos.

Estado: dominio y esquemas listos, 73 tests. Siguiente: tablas SQL y repositorios.

Documentación completa en [docs/README.md](docs/README.md).

Ejecutar: `python -m venv .venv`, `source .venv/bin/activate`, `pip install -r requirements.txt`, `pytest -q`.
